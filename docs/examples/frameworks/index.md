# Framework Examples
{: .fs-9 }

Complete examples for popular frontend frameworks with ViteKit.Msbuild.
{: .fs-6 .fw-300 }

Each example includes full project setup, configuration, and ASP.NET Core integration.

## Available Frameworks

### Vue + TypeScript
Modern Vue 3 application with full TypeScript support.

**[Vue + TypeScript Example](vue-typescript)**
: Single File Components, Vue Router, development and production builds

### React + TypeScript  
React 18 application with modern TypeScript setup.

**[React + TypeScript Example](react-typescript)**
: JSX/TSX support, React Router, ESLint configuration

### Svelte + TypeScript
Svelte application with TypeScript integration.

**[Svelte + TypeScript Example](svelte-typescript)**
: Svelte preprocessing, component-scoped styles, Svelte routing

{: .note }
> All framework examples follow the same patterns and can be easily adapted to other Vite-supported frameworks.

## Common Patterns

All framework examples demonstrate:

- ✅ **Zero-configuration** ViteKit.Msbuild setup
- ✅ **TypeScript** integration
- ✅ **Hot Module Replacement** during development
- ✅ **Production optimization** for release builds
- ✅ **ASP.NET Core** integration with controllers and views
